# beecount_extensions_bundle

Reserved for future capability composition, settings, extension UI, AI adapters, routes, and localization. Planned independent capabilities are notification collection, AI text enhancement, accessibility text enhancement, SMS collection, and HyperOS presentation. It will be BeeCount's only extension dependency after Phase 0 exits and implementation is explicitly approved.

Each capability directory contains a machine-readable `capability.json`. All current capabilities default off and remain non-executable during Stage 1.

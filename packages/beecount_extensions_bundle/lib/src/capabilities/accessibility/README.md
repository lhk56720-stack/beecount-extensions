# Accessibility text capability

Reserved for a first-phase optional enhancement that consumes minimized Android accessibility events from enabled payment apps.

- Defaults off and requires separate user authorization and an approved ADR.
- Uses target-package and payment-result-page guards.
- Does not click, type, capture screenshots, or write formal transactions.
- Degrades to notification collection when disabled, denied, unavailable, or incompatible.
- No executable implementation is approved during Phase 0.

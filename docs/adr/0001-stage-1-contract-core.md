# ADR-0001：批准 Stage 1 契约与纯 Dart 核心开发

- 状态：Accepted
- 日期：2026-08-23
- 决策者：项目所有者

## 背景

自动记账是首要扩展能力。Phase 0 已确定通知基础源、AI 智能兜底、无障碍独立可选增强、统一去重和 BeeCount 薄桥接方向。继续等待全部真机样本会阻塞与平台无关的契约和领域核心开发。

## 决策

批准创建并实现：

- `beecount_extension_api` 的纯 Dart DTO 和窄宿主端口；
- `beecount_automation_core` 的候选状态机、去重和自动入账决策；
- 对应的脱敏 fixture 与测试源码。

本阶段不批准：

- Android 生产服务、Manifest 或敏感权限；
- AI 网络调用、原始通知/无障碍文本出端；
- BeeCount Bridge 或正式账本写入；
- 超级岛实现；
- 任何 Flutter、Dart、Gradle、代码生成、依赖解析、编译或构建命令。

## 约束

- 金额使用整数最小货币单位；宿主未来负责与 BeeCount 当前 `double` 金额安全转换。
- AI、通知、无障碍和截图只产生候选或证据，不能直接调用正式交易接口。
- 自动入账不使用单一 AI 置信度；必须满足金额、方向、账户、关系和去重门禁。
- 10 分钟撤销只进入状态机和 API 语义；正式交易采用删除还是反向交易需单独 ADR。
- 不复制 GPL、无许可证或闭源项目代码。Stage 1 代码为独立实现。

## 后果

可以在没有 Android 权限和 BeeCount 数据库的情况下建立稳定、可测试的核心。由于当前禁止执行工具链，所有源码和测试在解除限制前均标记为“未编译、未执行”。

# ADR-0003：原始事件恢复与能力降级

- 状态：Accepted
- 日期：2026-08-23
- 决策者：项目所有者

## 背景

Android 可能在通知到达后、Dart 解析完成前终止进程。完全内存处理会丢事件，而宣称原生队列“恰好一次”在崩溃、重启和重复回调下并不可靠。通知监听、AI、无障碍和 SMS 又有不同的权限及隐私边界，不能因为一个能力失败而自动启用更高权限能力。

## 决策

### 事件边界

- 平台事件区分 `posted`、`updated`、`removed` 和 `snapshotChanged`。
- 通知被移除只表示系统生命周期变化，不代表交易撤销或退款。
- 采集器先用包名、来源 ID 和用户启用列表判断是否支持；不支持或未启用的来源不得复制正文。
- 原始文本 DTO 不提供 JSON 序列化；平台原始 event ID 只能存在于内存或加密恢复 payload。候选只保存 HMAC 来源身份、最小化结构字段和证据位置。

### 恢复队列

- 采用至少一次交付与 `lease / acknowledge / release / fail` 契约。
- 同一 capture ID 重复入队必须幂等；租约过期或主动释放后，未确认事件可再次交付。
- 可重试失败使用退避时间；永久失败立即销毁 payload，只保留带安全错误码的本地死信 tombstone。
- 租约支持续期；确认按单事件执行，因此批次可以部分成功。重复确认返回幂等结果，过期 token、错误 token 和不属于该租约的事件必须返回明确状态且不得改变数据。
- 队列 API 始终用 `captureId` 确认或标记失败，不得传 raw event ID 或来源 HMAC。只有 `leased` 状态可以保存租约 token 哈希和租约过期时间；其他状态必须清空两者。
- 续租只延长短期处理所有权，返回的租约时间不得超过该记录从首次入队计算的 24 小时绝对过期时间。
- 同一来源事件重放必须生成稳定候选 ID；每个账本只允许一个串行入账协调器。通过候选更新、统一去重和宿主幂等入账键实现“业务有效一次”，不承诺队列恰好一次。
- 相同幂等键和相同命令重试返回 `alreadyApplied`；相同键携带不同命令必须返回 `idempotencyConflict` 且不写账。
- 恢复记录只能位于应用私有存储，敏感 payload 必须加密；不得进入日志、Android Auto Backup、BeeCount 云同步、导出或 AI 请求。
- 明文 envelope 只保存来源 HMAC、生命周期和队列调度元数据；完整 `CapturedAutomationEvent`（包括原始 event ID、替换关系和文本片段）只能位于带版本的加密 payload。payload 版本必须取自 `CapturedAutomationEvent.currentPayloadSchemaVersion`，不得由 Android 实现另写常量。解密或迁移失败时不得猜测恢复，必须销毁 payload 并记录安全错误码。
- 候选的 `sources` 是审计来源历史：同一 HMAC 身份更新时替换原项；新 HMAC 显式 `supersedes` 旧项时保留旧项但标为非当前。非当前或 removed 来源不得提供证据，入账只使用当前已启用且非 removed 的来源证据。
- 原始记录从首次入队起绝对最长保留 24 小时；重试和死信不能延长。成功消费后立即删除。

### 能力与权限降级

- 自动记账总开关、通知、AI、无障碍、SMS 和展示能力分别管理；默认全部关闭。
- 首次启用敏感能力时只解释并请求该能力所需权限；拒绝后不循环弹窗。
- 已启用权限被撤回时立即停止该采集器，状态显示不可用并提供一次明确修复入口；不得静默切换到无障碍、SMS、截图、Shizuku 或 Root。
- AI 只在本地解析仍缺少必要字段且 AI 能补足时智能调用；AI 未启用或失败时保留待确认候选。
- 用户主动关闭来源或总开关时停止新采集，并清除对应未消费原始队列；结构化候选保留供用户处理。

## 后果

- 进程终止后可以恢复尚未解析的事件，同时容忍重复交付。
- 权限状态和用户开关不会互相隐式升级，使用界面只需展示总开关、能力开关及需要处理的异常状态。
- Android 队列实现必须通过崩溃恢复、重复入队、租约超时、退避、永久失败和 24 小时清理测试后才能进入生产。

## 隐私与权限影响

本 ADR 约束未来可能落盘的短期敏感数据，但不批准任何 Android Service、Manifest 或权限声明。通知监听、无障碍、SMS 和 AI 数据出端仍需各自实现审查；主动截图、Shizuku、Root、Xposed 和私有 Hook 不在首期范围。

10 分钟撤销目前只定义候选状态和时间窗。正式账单采用删除还是反向交易尚未批准，必须另写 ADR；本阶段不得为实现撤销而增加宿主删除接口。

## 回滚策略

可关闭恢复队列并回到纯内存处理，代价是进程终止时可能漏记。任何回滚都不得改用明文持久化或延长 24 小时保留期。
